# Reasoning engine with verifier scoring (lst-3.14)

Implements three reasoning strategies with timeouts, verifier scoring, tree pruning, and cancellation of surplus parallel requests behind a client interface.

- **Class:** Runs on its own
- **Needs:** Python 3.12+; `pydantic` (`pip install -r requirements/quickstart.txt`)
- **Run:** `python chapters/ch03/lst-3.14.py`
