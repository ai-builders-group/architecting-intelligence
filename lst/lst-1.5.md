# Semantic similarity assertions (lst-1.5)

Compares sentence embeddings with cosine similarity and raises an assertion when text similarity falls below a threshold.

- **Chapter:** 01
- **Class:** Needs service huggingface-download
- **Needs:** Python 3.12+; `numpy`, `sentence-transformers` (`pip install -r requirements/ml.txt`); a Hugging Face model download (see [SERVICES](../docs/SERVICES.md))
- **Run:** `python chapters/ch01/lst-1.5.py`
