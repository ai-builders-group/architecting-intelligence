# Image quality confidence calibration (lst-9.5)

Measures image quality, applies confidence penalties, and optionally calibrates adjusted scores using logistic or isotonic regression.

- **Chapter:** 09
- **Class:** Runs on its own
- **Needs:** Python 3.12+; `numpy`, `pillow`, `pydantic`, `scikit-learn`, `scipy` (`pip install -r requirements/core.txt`)
- **Run:** `python chapters/ch09/lst-9.5.py`
