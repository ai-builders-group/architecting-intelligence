# Document summaries prepended for embeddings (lst-9.8)

Generates a document summary, prepends it when embedding each chunk, and stores the original chunk text separately.

- **Chapter:** 09
- **Class:** Needs service llm-api-key
- **Needs:** Python 3.12+; `langchain-text-splitters`, `openai`, `pydantic` (`pip install -r requirements/llm.txt`); an LLM API key (see [SERVICES](../docs/SERVICES.md))
- **Run:** `python chapters/ch09/lst-9.8.py`
